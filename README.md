# BurdenOfPerturbation
Code for preprint: Kimball and Baker (2026)


### There are two main rmd files to run here.

#### DataAnalysis
This runs the data analysis done on the data and produces figures 1 and parts of 5

#### MechanisticModels
This file is much longer and contains the code to run the RSV and flu model as well as all extensions. This generates figures 2,3,4, and parts of 5.

### There are also 3 folders

#### source
contains scripts for all the functions referenced in the rmd files. See scripts for description of each.

#### Japan_surveillance_2015_2023 
contains extracted Japan Surveilence data.

#### figures
contains all generated figures
